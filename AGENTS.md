# AGENTS.md

Astro 5 personal site (static, deployed to Vercel). MDX content collections, Tailwind CSS v4 (CSS-first via `@tailwindcss/vite`), Preact islands, KaTeX math, sitemap.

## Commands

- `npm run check` (`astro check`) is the **only** type/lint gate — there is no separate `tsc` script, ESLint, Prettier, or Biome config.
- `npm test` runs `vitest run`, but the repo has **zero test files**; it passes vacuously. Add tests plus a vitest config if you need them.
- `dev` / `build` / `preview` are the standard Astro scripts; `build` outputs to `dist/`.

## Content

- Blog and project entries are MDX files in `src/content/blog/` and `src/content/projects/`; `src/pages/**/[...slug].astro` renders them via the content loader.
- Frontmatter is validated by Zod schemas in `src/content/config.ts`. Required: blog = `title`, `date`, `excerpt`; projects = `title` only. Add new frontmatter fields to the schema or validation fails.
- Homepage content (hero, about, experience, education, project cards) lives in the typed data file `src/data/profile.ts`, not in the components.
- Interactive components in MDX are **Preact** islands (`.tsx` with a `client:*` directive, e.g. `<AlphaBetaVisualizer client:load />`). `tsconfig.json` sets `jsxImportSource: preact` — write Preact, not React.
- TeX math works in MDX (remark-math + rehype-katex in `astro.config.mjs`); KaTeX CSS is imported only by `src/layouts/ArticleLayout.astro`, so math renders styled on article pages only.
- Per-post OG image: set `ogImage` in frontmatter. OG images are committed static files under `public/`, generated manually with `node scripts/build-og.mjs` — not part of the build.
- `resources/` is offline source material (resume templates, case-study PDFs) and is **not served**; linkable assets must go in `public/`.

## Conventions & gotchas

- **Tailwind v4 is CSS-first**: no `tailwind.config.js`. Theme tokens live in `src/styles/global.css` via `@theme`/`@custom-variant`; dark mode is the `.dark` class on `<html>`.
- `package.json` pins `vite` to `6.4.3` via `overrides` (`@tailwindcss/vite` types lag Astro's bundled Vite). Keep the pin unless upgrading Astro and Tailwind together.
- `.astro/types.d.ts` is generated by `check`/`build` and gitignored — don't hand-edit it.
- Analytics (Plausible/Umami) inject only when `PUBLIC_ANALYTICS_SRC` is set; see `.env.example`. Unset = no analytics.

## Deploy

- Vercel, `npm run build` → `dist/`. Only **`main`** auto-deploys (`vercel.json` `deploymentEnabled.main`); other branches produce no deployments.
